# duet-work

Навыки совместной работы человека и агента. Ни один не подхватывается по смыслу разговора: у всех в шапке `disable-model-invocation: true`, включает только человек слэш-командой.

## `duet-work-full`

Формат беседы с человеком и устройство рабочей папки. Промпт и ответ разбираются на адресуемые мысли: у каждой свой номер и свой класс, поэтому на мысль можно сослаться, по ней можно спросить, что осталось без ответа, и видно, чего собеседник ждёт от каждого абзаца, не дочитывая его. Вторая половина — рабочая папка: `INDEX.md` ведёт агент, `NOTES.md` ведёт человек.

## `duet-work-clean`

Нумерация ответов и выбор их размера. Ответ открывается заголовком `## Response RX`, а объём выбирается одним из трёх путей: план на несколько ходов, размеченный разделами ответ или короткая проза до 200 слов.

## Подключение

Репозиторий объявляется в `git_repos` контекста, навыки — в `skills`:

    "git_repos": { "duet-work": "git@github.com:alatyshau/duet-work.git" }
    "skills": [ "@duet-work.git/skills/duet-work-full" ]
