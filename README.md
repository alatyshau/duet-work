# duet-work

Дом навыка `duet-work-full` — формат беседы с человеком и устройство рабочей папки.

Навык задаёт две вещи. Первая — разбор промпта и ответа на адресуемые мысли: у каждой свой номер и свой класс, поэтому на мысль можно сослаться, по ней можно спросить, что осталось без ответа, и видно, чего собеседник ждёт от каждого абзаца, не дочитывая его. Вторая — рабочая папка: что лежит в её корне и кто что ведёт — `INDEX.md` ведёт агент, `NOTES.md` ведёт человек.

Навык не подхватывается по смыслу разговора: в шапке стоит `disable-model-invocation: true`, поэтому включить его может только человек командой `/duet-work-full`.

Репозиторий подключается к контексту Duet объявлением в `git_repos`, навык — в `skills`:

    "git_repos": { "duet-work": "git@github.com:alatyshau/duet-work.git" }
    "skills": [ "@duet-work.git/skills/duet-work-full" ]
