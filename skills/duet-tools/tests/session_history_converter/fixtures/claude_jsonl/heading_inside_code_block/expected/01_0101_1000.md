How do I restart the service?

## Final Response: Restart procedure
[timestamp:: 2026-01-01 10:00:01]

Stop it first:

```bash
# stop the service before touching config
systemctl stop app
```

The config file looks like this:

```
## database section
host = localhost
```

Then start it again.
